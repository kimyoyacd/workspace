# 구현 완료 및 QA 체크리스트

## 구조

- [ ] 좌측 전역 메뉴와 상단 로컬 탭이 같은 항목을 반복하지 않는다.
- [ ] 홈은 상단 로컬 탭 없이 기간·팀 필터만 사용한다.
- [ ] 프로젝트는 전역 메뉴가 아니라 운영 현황의 하위 개체다.
- [ ] 전체 AX 시스템이 `워크플로우`의 첫 탭에 있다.
- [ ] 제안·RFP가 3개 제작 서비스와 동급으로 오인되지 않는다.

## 홈

- [ ] 첫 화면에서 진행 중 프로젝트 수가 보인다.
- [ ] 가동 리소스와 유휴 리소스가 가장 큰 숫자 중 하나로 보인다.
- [ ] 프로젝트 표·개인별 가동률·위험 사유·Gate 목록·예측 그래프가 홈에 노출되지 않는다.
- [ ] HTML 레퍼런스 수준의 여백과 카드 수가 유지된다.
- [ ] 모든 KPI가 상세 화면의 해당 필터로 연결된다.

## 운영 현황

- [ ] 프로젝트 현황 탭에서 프로젝트별 단계·담당·D-day를 볼 수 있다.
- [ ] 리소스·위험 탭에서 담당자별 가동률·가용 시간·과부하 원인을 볼 수 있다.
- [ ] 일정·Gate 탭에서 Human Review·방향 결정·최종 승인 대기를 분리해 볼 수 있다.
- [ ] 운영 요약 탭에서 2주 가용 용량과 예정 수요를 비교할 수 있다.
- [ ] 프로젝트 현황에서 테이블·보드·간트 보기를 전환할 수 있다.
- [ ] 간트에서 일·주·월 전환, Task 하위 행, 의존성, Milestone, Gate, 오늘 기준선을 볼 수 있다.
- [ ] Task·스프린트에서 주간 타임라인·Kanban·목록을 전환할 수 있다.
- [ ] 개인별 현재 투입 프로젝트·Task·배정시간·실제시간·다음 가용일을 볼 수 있다.
- [ ] 프로젝트별 참여자·역할·배정시간·투입률·미배정 역할을 볼 수 있다.

## 데이터

- [ ] 시안의 예시 숫자가 하드코딩되지 않았다.
- [ ] 데이터 출처와 마지막 동기화 시간이 표시된다.
- [ ] loading·empty·error·stale 상태가 구현됐다.
- [ ] mock 사용 시 `샘플 데이터`가 표시된다.
- [ ] 가동률 산식과 임계값이 설정에서 관리된다.
- [ ] 기존 Notion·Google Sheets 연동이 보존된다.

## 사용설명서·Playbook

- [ ] `AI 실행 환경` 아래 Claude Code 사용설명서가 로컬 탭을 가진다.
- [ ] 3개 제작 워크플로우에 각각 사용설명서가 있다.
- [ ] 인물 Identity 9단계가 빠지지 않는다.
- [ ] 모든 영상 유형에 사운드 단계가 있다.
- [ ] 온보딩이 설명서를 복제하지 않고 딥링크한다.
- [ ] 각 문서에 Owner·버전·최근 수정일이 있다.

- [ ] 포인트 컬러가 그래프·태그·상태점에만 쓰인다.
