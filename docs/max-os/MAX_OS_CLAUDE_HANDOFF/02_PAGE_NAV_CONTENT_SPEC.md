## 홈 `/`

홈의 1순위는 MAX OS의 메시지와 오늘의 핵심 상태를 숨 쉬는 여백 안에서 빠르게 전달하는 것이다.

### 첫 화면 필수 콘텐츠

1. Hero: `Hello`와 MAX OS 메시지. `MAX_OS_HOME_WIREFRAME.html`의 여백과 비중 유지.
2. 오늘의 운영: 진행 중 프로젝트 · 승인 대기 · 7일 내 마감 · 위험 프로젝트의 숫자만 표시.
3. 리소스 요약: `가동 리소스`와 `유휴 리소스`를 큰 숫자로 표시.
4. 업무 시작: 3개 제작 워크플로우 진입.
5. 처음이라면: MAX OS 이해와 첫 실행 경로.

### 하단 보조 콘텐츠

- 최근 구축된 시스템
- 마지막 동기화 시간과 데이터 출처

홈에는 프로젝트 표, 개인별 가동률, 위험 사유, Gate 대기 목록, 예측 그래프를 넣지 않는다. 홈 숫자를 선택하면 `운영 현황`의 해당 로컬 탭과 필터로 이동한다.

## 운영 현황 `/operations`

- 홈의 요약 수치를 상세 분석한다.
- 프로젝트·리소스·Gate를 한 지표로 합치지 않는다.
- 모든 KPI와 차트는 필터가 적용된 상세 화면으로 연결한다.
- `운영 요약`: 프로젝트 단계 분포·주요 위험·Gate·2주 수요를 요약한다.
- `프로젝트 현황`: 프로젝트별 단계·담당·D-day·상태를 표시한다.
- `Task·스프린트`: 주간 타임라인·Kanban·Task 목록과 일·주·월 간트를 표시한다.
- `일정·Gate`: Human Review·방향 결정·최종 승인 대기와 일정을 표시한다.
- `리소스·위험`: 담당자별 가동률·가용 시간·현재 투입 프로젝트·Task·과부하 원인·유휴 인력을 표시한다.
- `팀·조직`: 역할·스쿼드·책임 범위를 표시한다.

## 워크플로우 `/workflows`

- 첫 탭 `전체 AX 시스템`에 Figma `272:2`의 전체 흐름을 표시한다.
- `제안·RFP`는 제작 서비스가 아니라 3개 제작 흐름으로 연결되는 앞단 경로다.
- 제작 흐름은 `UI 구축·콘텐츠 제작 / AI 비주얼 에셋 / AI 영상·필름` 세 개다.

## 온보딩과 설명서의 관계

- 온보딩: 역할별로 무엇부터 학습할지 안내하는 학습 경로.
- 사용설명서: 실제 화면과 업무를 어떻게 사용하는지 설명하는 실행 문서.
- Playbook: 업무 유형별 단계·입력·산출물·Gate·품질 기준.
- 동일 본문을 복제하지 않고 온보딩에서 설명서와 Playbook으로 링크한다.
