# 운영 현황 상세 화면 필수 명세

## 목적

홈은 핵심 숫자만 보여주고, `운영 현황`에서 프로젝트·Task·일정·Gate·리소스 투입을 빠짐없이 조회한다. 기존 Dashboard v8의 데이터와 기능은 삭제하지 않고 아래 화면으로 재배치한다.

참고 자료:

- Dashboard v8: `https://deploy-preview-30--luxury-griffin-44f528.netlify.app/docs/maxosdashboardv8.html`
- 화면 참고: `references/OPERATIONS_TASK_GANTT_REFERENCE.png`
- 상세 카드·그래프 참고: `references/MAX_OS_OPERATIONS_OVERVIEW_REFERENCE.png`

## 공통 필터

모든 운영 탭에서 다음 필터를 공유한다.

- 기간: 오늘 · 이번 주 · 다음 주 · 월 · 분기 · 직접 지정
- 조직: 전체 · VM · VX · 스쿼드 · 담당자
- 프로젝트: 전체 · 클라이언트 · 프로젝트명
- 업무 유형: UI 구축·콘텐츠 제작 · AI 비주얼 에셋 · AI 영상·필름
- 상태: 예정 · 진행 · 검수 · 승인 대기 · 완료 · 보류 · 위험
- 보기 단위: 일 · 주 · 월

필터 상태는 URL query에 저장하고 다른 탭으로 이동해도 유지한다.

## 1. 운영 요약 `/operations/overview`

필수 콘텐츠:

- 진행 중 프로젝트 · 신규 인입 · 승인 대기 · D-7 마감 · 위험 프로젝트
- 가동 리소스 · 유휴 리소스 · 과부하 인원 · 전체 가동률
- 주간 완료 Task 추세
- 프로젝트 단계 분포
- Gate 적체와 평균 대기시간
- 2주 가용 용량 대 예정 수요
- 오늘 결정할 항목 · 데이터 누락 · 추가투입 필요

이 탭은 상세 목록을 압축해 보여주며 모든 수치·차트는 해당 상세 탭으로 이동한다.

## 2. 프로젝트 현황 `/operations/projects`

상단 보기 전환:

`테이블 / 보드 / 간트`

### 테이블 보기

필수 열:

- 프로젝트·클라이언트
- 서비스 유형·하위 유형
- 현재 단계·진척률
- 프로젝트 Owner·참여 인력
- 시작일·마감일·D-day
- 현재 Gate·결정권자
- 계획 시간·실제 시간
- 상태·위험 등급·위험 사유
- SoT 링크·최근 동기화

### 보드 보기

상태 열:

`예정 / 진행 중 / Human Review / 수정 / 완료 / 보류`

카드에는 프로젝트명, 현재 단계, Owner, 참여자, D-day, 위험, Gate를 표시한다.

### 간트 보기

필수 기능:

- 일·주·월 단위 전환
- 프로젝트별 행과 Task별 하위 행 펼침·접기
- Task 시작일·종료일·기간·진척률 표시
- Task 의존성 연결선
- Milestone·Human Gate·납기 마커
- 오늘 기준선
- 담당자·팀·상태·프로젝트 필터
- 지연 Task·일정 충돌·미배정 Task 표시
- 계획 일정과 실제 일정 비교

## 3. Task·스프린트 `/operations/tasks`

상단 보기 전환:

`주간 타임라인 / Kanban / 목록`

### 주간 타임라인

- 월요일부터 일요일까지 주 단위 표시
- 프로젝트·스프린트별 Task 배치
- Task 기간·담당자·우선순위·상태·의존성 표시
- 이전 주·다음 주 이동과 날짜 직접 선택
- 일·주·월 확대 수준 제공

### Kanban

열:

`할 일 / 진행 중 / 검수 중 / 승인 대기 / 완료 / 차단`

Task 카드 필수 정보:

- Task ID·이름
- 소속 프로젝트·현재 워크플로우 단계
- 담당자·협업자
- 시작일·마감일·예상 시간·실제 시간
- 우선순위·상태·Gate
- 의존 Task·차단 사유
- 산출물·근거 링크

## 4. 일정·Gate `/operations/gates`

- 전체 일정 캘린더: 일·주·월
- 프로젝트·Task·Milestone·Gate 통합 표시
- Human Review · 방향 결정 · 최종 승인 큐 분리
- 요청일·SLA·결정권자·대기시간·지연 영향
- Gate 필수 근거와 충족 여부
- READY · CONDITIONAL · REVISION · BLOCKED 상태
- 결정·피드백·재요청 이력

## 5. 리소스·위험 `/operations/capacity`

### 팀 요약

- 전체 인원 · 가동 · 유휴 · 과부하 · 미기록
- 전체·팀별 가동률
- 주별 가용시간 대 배정시간
- 향후 2주·4주 수요 예측

### 개인별 리소스 매트릭스

행은 구성원, 열은 주 단위로 표시한다.

- 이름·역할·팀
- 주별 표준 가용시간
- 확정 배정시간·예정 배정시간
- 가동률·잔여 가용시간
- 투입 프로젝트와 각 프로젝트 배정시간
- Task 수와 이번 주 마감 수
- 다음 가용일
- 유휴·적정·과부하·휴가·기록 누락 상태
- 프로젝트 간 일정 충돌과 추가투입 경고

구성원을 선택하면 상세 패널에서 다음을 표시한다.

- 현재 투입 프로젝트 전체
- 프로젝트별 역할·배정률·기간
- 담당 Task·Gate·마감일
- 주별 계획시간·실제시간
- 다음 예정 프로젝트
- 유휴 구간·과부하 구간·재배정 제안

### 프로젝트별 투입 현황

- 프로젝트별 총 계획시간·실제시간
- Owner·참여자·역할
- 구성원별 배정시간·투입률·기간
- 미배정 역할·필요 역량·FTE 갭
- 외주·추가 채용·일정 조정 필요 여부

## 6. 팀·조직 `/operations/team`

- 구성원·역할·팀·보유 역량
- 현재 투입 프로젝트·담당 Task
- 가동률·가용시간·다음 가용일
- 휴가·외주·채용 상태
- 역할 중복·미보유 역량·병목 구간

## 7. 클라이언트 `/operations/clients`

- 클라이언트별 진행 프로젝트·상태·건강도
- 총 요청·진행·완료·지연 수
- 최근 접점·다음 일정·담당자
- 매출·계약 정보는 권한이 있을 때만 표시

## 8. 프로젝트 상세 `/operations/projects/:id`

상단 탭:

`요약 / Task / 일정·간트 / 리소스 / Gate·Review / 산출물 / Project SoT / 이력`

- `Task`: 프로젝트의 전체 Task와 상태·담당·시간
- `일정·간트`: Task 의존성·Milestone·Gate·납기
- `리소스`: 참여자별 역할·기간·배정시간·실제시간·투입률
- `Gate·Review`: 승인 요청·근거·결정·피드백 이력
- `산출물`: 버전·QA·권리·최종본
- `Project SoT`: 공식 기준 원본과 최근 동기화
- `이력`: 상태·담당·일정·Gate 변경 로그

## 필수 데이터 개체

- `Project`: 프로젝트 기본 정보·기간·상태·위험·SoT
- `Task`: 프로젝트·단계·담당·기간·상태·진척·의존성·시간
- `Assignment`: 구성원과 프로젝트·Task 간 역할·배정시간·기간
- `Member`: 역할·팀·주별 가용시간·상태
- `TimeEntry`: 계획시간·실제시간·기록일
- `Milestone`: 납기·중간점검·Gate 일정
- `Gate`: 요청·결정권자·근거·상태·SLA·결정 이력
- `Risk`: 원인·영향·심각도·Owner·완화조치

## 완료 판정

다음 질문에 모두 답할 수 있어야 한다.

1. 이번 주 프로젝트별로 어떤 Task가 진행되는가?
2. Task별 담당자·기간·상태·의존성은 무엇인가?
3. 한 사람은 현재 어떤 프로젝트와 Task에 얼마나 투입되어 있는가?
4. 한 프로젝트에는 누가 어떤 역할로 얼마나 투입되어 있는가?
5. 다음 2주에 누가 유휴 또는 과부하가 되는가?
6. 어떤 프로젝트와 Task가 지연·차단·승인 대기 상태인가?
7. 일정·Task·리소스·Gate 변경 근거와 최신 동기화 시점은 무엇인가?

하나라도 확인할 수 없으면 운영 현황 구현은 완료로 판단하지 않는다.
