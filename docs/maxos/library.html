공식 기준 문서 (Project SoT)

Project SoT는 프로젝트마다 하나씩 두는 공식 기준 문서예요. 확정된 방향·승인 기록·최종 산출물의 위치를 한 문서에 모아, "무엇이 최종인가"를 이 문서 하나로 판단해요.

실행→ Human Review→ Project SoT 기록→ 승인 자산 보관

지금은 어디서 보나요?

현재는 각 프로젝트의 Notion 페이지가 공식 기준 문서 역할을 해요. 보관함 안으로 모으는 연결은 준비 중이에요.

진행 중인 일에서 Notion 링크 확인하기 → 연결 안 됨

공식 기준 문서에 담기는 것

  • 확정된 방향과 결정 근거
  • Human Review·Gate 승인 기록
  • 최종 산출물의 위치와 버전
  • 자산화·재사용 결과

사용·학습

자산이 실제로 어떻게 쓰였는지를 누적하는 곳이에요. 잘 된 것과 안 된 것을 함께 남겨서, 다음 프로젝트가 같은 시행착오를 반복하지 않게 해요.

여기에 기록될 이력

  • 사용처 — 어떤 프로젝트·채널에서 다시 쓰였는지
  • 성과 — 사용 결과와 클라이언트 반응
  • 프롬프트·모델 — 재현에 필요한 생성 조건
  • 실패 이력 — 재작업 원인과 피해야 할 조합
