## UI 어포던스 · 문장 개선 (2026-08-20)

실장 피드백: "클릭해서 볼 수 있다고 판단이 안 서는 UI 버튼 타입이 있다", "여전히 전체 이해도와 수준을 쉽게 이해하기 어렵다"

**어포던스 — 누를 수 있다는 걸 눈에 보이게**
- 갈래 헤더에 원형 ＋ 버튼. 펼치면 −로 전환, hover 시 검정 반전
- 접힌 갈래에 "＋ 를 누르면 순서가 열립니다" 힌트 한 줄
- 하위 유형 카드에 → 화살표, 선택되면 ✓로 전환
- 에이전트 칩의 복사 표시를 "⧉ 복사"로 구분선과 함께 명시
- `aria-expanded` 부여

**문장 — dumbify + anti-ai-writing 스킬 실제 적용**
- 기준: `.claude/library/mail-tone.md` (담백하되 통보가 아닌 공유)
- 한 문장에 하나의 정보로 쪼갬. "정식 명칭은 ~예요" 같은 부담 요소 제거
- 라벨 교체: 받을 것 → **필요한 것** / 만들 것 → **나오는 것** / 여기서 부르는 것 → **도와주는 것**
- 전문어 제거: "디렉터 방향 컨펌" → "디렉터가 방향을 봅니다"
- anti-ai-writing 적발분 수정: 부정 병렬("만드는 갈래가 아니라 그 앞단") 삭제, 가짜 범위("메일이든 미팅이든") 삭제
- 어미를 "~합니다/~됩니다" 공유형으로 통일

## 홈 = 대시보드로 전환 (2026-08-20 · 실장 지시)

실장 피드백: "홈은 첨부처럼 여백 있고 깨끗하면서 그래프가 섞인 무드여야 한다. 운영 현황의 카드보기·간트·업무 배정·우리 팀이 홈에 다 녹아야 하고, 워크플로우 바로가기는 워크플로우 탭에서 보이면 된다. 홈은 인삿말 + 진행 중인 일 위주 다이어그램·그래프·가동률."

앞서 만든 「버튼 3개 + 점진적 공개」 홈은 폐기. 홈이 곧 대시보드.

**홈 구성 (index.html)**
1. 히어로 — `Hello 👋` + 3줄 대형 타이포. 우측에 ＋ 바로가기 3개(운영 현황 / 업무 시작 / 처음 사용). 첨부 시안의 여백·정렬을 따름
2. 오늘의 운영 — **동시에 돌아가는 일 곡선**(지난 6주~앞으로 8주, 오늘 점 표시) + 숫자 3(진행 중 / 이번 주 마감 / 살펴볼 일) + 일의 진행 단계 세그먼트 + 업무 유형 구성
3. 지금 살펴볼 일 — 날짜 뒤집힘 · 마감 지남 · 임박 · 시간 미기록
4. 진행 중인 일 — 카드 보기 ⇄ 일정(간트, 일/주/월)
5. 사람·업무 배정 — KPI 4칸을 누르면 아래 구성원 목록이 그 상태만 남음(같은 칸 다시 누르면 해제)
6. 우리 팀 — 3그룹 9명, 배정률 연동

**곡선의 근거**: 시간 기록 시트에 일별 시계열이 없어 가짜 곡선을 그릴 수 없음. 대신 프로젝트 시작~마감 구간의 **주차별 겹침 수**를 세서 실데이터로만 그림. "언제 몰리는지"가 보임.

**운영 현황 축소 (operations.html)**: 6탭 → 3탭(진행 중인 일 / 이번 주 할 일 / 일정·승인). 한눈에 보기·사람 배정·우리 팀 탭 제거(홈으로 이관), 진행 중인 일은 표 하나만 남김. 딥링크 필터(due7·late·conflict·group)는 유지.

**공용 모듈 분리**: `assets/ops.css` + `assets/ops-views.js` — 카드보기·간트·배정률·팀·세그먼트·곡선 렌더러를 홈과 운영이 공유. 같은 화면을 두 번 만들지 않음.
