## 🪝 훅 우선 구조 (2026.08.07 확정 — 전 시리즈 표준, 기존 5샷 구조 대체)
> **문제**: 기존 구조는 0~2초가 세팅 컷이라 타격감이 3초 이후에 시작 → Shorts의 `viewed vs swiped away` 구간을 버림.
> **해법**: **페이오프를 맨 앞에** 놓고, 곧바로 시청자를 놀이에 초대한다.

| 구간 | 내용 | 목적 |
|---|---|---|
| **0.0–0.5s** | **콜드 오픈 = 가장 강한 피날레 순간을 먼저** (BOOM + 컨페티 + 펀치인, 빌드업 없음) | 스와이프 차단 |
| **0.5–1.2s** | 캐릭터가 카메라 쪽으로 몸 기울여 **"COPY THE BEAT!"** 도발 (도구로 시청자 가리킴) | 참여 유도 |
| **1.2–11s** | TAP → ROLL → COMBO, 동작과 정박 정확 싱크 | 본편 |
| **11–14s** | BOOM 피날레 + 컨페티 | 페이오프 |
| **14–15s** | **첫 프레임과 동일 포즈로 복귀** → 심리스 루프 | 반복 재생 |

**질문형 훅 규칙**: `Can JUNI...?` ❌ (시청자가 답을 이미 앎) → **`Can YOU copy this beat?`** ✅ (시청자를 놀이 안으로).
- 보이스 콜아웃도 이 구조에 맞춰 생성: `"Boom! ... Copy the beat! ... Tap! ... Roll! ... Combo! ... Boom!"`
- 테이 요리 시리즈도 동일 적용: 콜드 오픈=완성 리빌, 도발="Can you cook this fast?" / "Copy the recipe!"
- 프롬프트 Negative에 `slow build-up, calm opening` 추가 필수.
