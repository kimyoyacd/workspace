## 요약 (매 세션 종료 시 갱신)

- **핵심 결정사항**: 브랜드명 "Boomi". 바이오 소재 무전원 부메랑 + 폰으로 비행만 관찰(아이는 화면 안 봄). 시드 정령 마스코트, 세이지그린·허니앰버 컬러.
- **결정 근거**: 보호자의 "화면 의존" 우려가 핵심 구매 게이트라고 판단 → AI는 비주얼 제작 도구로만 사용, 제품 자체엔 AI 미탑재·카피에서도 AI 언급 없음. 상세 논의는 01-research.md·03-strategy.md 참조.
- **다음 액션**: 변주 프롬프트(패키지 목업 / 배너 / 계절별 캐릭터 시트 4종) 생성 대기. 클라이언트 확정 시 양산 전환(어린이제품안전특별법·KC 인증) 검토 필요.
