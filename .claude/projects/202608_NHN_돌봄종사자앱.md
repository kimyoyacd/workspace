- **클라이언트**: NHN (보건복지부 AI 스마트홈 돌봄 사업 주관기관, AX-Sprint 과제 / 실증 경기·전남 400가구)

## 요약 (매 세션 종료 시 갱신)

- **핵심 결정사항**
  1. 견적은 **중급 0.75 + 초급 0.35 = 1.10 M/M 조합으로 9,010,000원**(만원 절사) 안을 최종 후보로 둠. 이전 후보는 14,200,000원(1.75M/M) → 10,160,000원(1.25M/M).
  2. 실제 투입은 **메인 1인 3주 풀 + 팔로업 1인 약 1주 = 1.00 M/M**. 판관비 750만원/인월 기준 원가 750만원 → 9,010,000원 기준 실질 마진 약 151만 원(17%).
  3. 1단계는 **시안 2~3안 제시가 아니라 사전 톤앤무드 협의 → 1개 방향 확정** 방식으로 진행. 1인 체제 마진 구조와 정합.
  4. 메일에서 "범위 외" 부정형 반복을 제거하고 제약 조건을 "확인 사항" 한 섹션으로 통합. 일정에 ±2~3일 버퍼 문구 삽입.
  5. 리서치 산출물은 신규 스킬 `tab-deck-design`으로 제작 (좌측 탭 SPA HTML 1장).

- **결정 근거**
  - 견적서상 M/M(1.25~1.10)과 실제 투입(1.00)의 차이가 마진의 원천. 견적서상 M/M을 실투입과 동일하게 잡으면 마진이 7%대로 떨어짐.
  - Figma 기능명세서 v0.1.0 확보로 과업 실체가 드러남 — FR1~55, 화면 ID 28개, 사용자 2종(요양보호사 4단계 / 생활지원사 3단계 기록 분기).
  - **3주 확약 보류 사유**: ① 「와플랫 공공 — AI 생활지원사」 앱이 이미 운영 중인데 이번 앱과의 관계 불명 ② 디자인 대상 화면 총량 미확정(ID 28개 외 상태·예외 화면 미집계) ③ FR50 앱 내 글자 크기 조정 대응 범위 미정 — 단계 수 × 컴포넌트 수만큼 검수량 증가 ④ NHN 디자인 시스템 유무 불명 ⑤ 컨소시엄 다자 구조로 승인권자 불명확.

### 2026-08-10

**견적 검토 경과 (3회 개정)**
- 1안: UI Design 중급 1.00 + 초급 0.75 = 1.75 M/M → 직접인건비 11,740,146 → 제경비110%·기술료20% → 견적 29,585,169 → 할인 52% → **14,200,000원**
  - 판관비 750만/인월 기준 원가 13,125,000원 → 마진 1,075,000원(7.6%). 버퍼 없음으로 판단.
- 2안: 중급 0.75 + 초급 0.50 = 1.25 M/M → **10,160,000원**
  - 원가 9,375,000원 → 마진 785,000원(7.7%). 퍼센트는 비슷하나 절대 이익이 오히려 감소. 투입량도 줄어 스코프 소화 부담 증가.
- 3안(최종 후보): 중급 0.75 + 초급 0.35 = 1.10 M/M → 직접인건비 7,453,972 → 견적 18,784,009 → 할인 52% → **9,010,000원**
  - 사용자가 "900만원 초반대" 목표 제시. 다른 조합 비교: 초급 0.30 → 863만(미달) / 0.38 → 925만 / 중급1.00+초급0.10 → 920만. 0.35가 가장 깔끔하게 목표 구간에 안착.
- **실투입 전제 변경이 결정적**: 사용자가 "메인 1명, 1명은 한 주 정도 팔로업 또는 혼자 가능한 수준"으로 진행 의사 표명 → 실투입 1.00 M/M, 원가 750만원. 9,010,000원 기준 마진 17%로 개선.

**메일 초안 4회 개정**
- 초안: 3단계 일정표 + 견적만. → 아이콘·이미지 최적화가 3단계에 명시 안 됨을 지적.
- 2차: 3단계 범위 명시 추가. → 검토 결과 마찰 지점 5개 발견:
  ① "범위 외" 표현 2회 반복 → 고객사가 방금 요청한 항목에 연속 거절로 읽힘
  ② 제약 조건이 메일 전체에 4번 분산 → 착수 전부터 방어적 인상
  ③ "세부 수정 중심"의 기준 부재 → 해석 분쟁 소지
  ④ 1단계 지연 책임이 고객사에만 있는 것처럼 읽힘
  ⑤ "재산정/별도 협의" 4회 등장 → 경계심 유발
- 3차: ①을 "포함하되 이런 형태로 정리됩니다"로 전환, ②를 "확인 사항" 한 섹션으로 통합, ④에 우리 준비 의무 병기, 리소스 비전담 이슈를 ±2~3일 버퍼 문구로 완충.
- 4차(최종): 1단계를 "2~3안 제시 → 1안 확정"에서 **"톤앤무드 사전 협의 후 1개 방향 확정"**으로 변경. 고객사가 이미 생각해둔 무드가 있으면 그 방향으로 바로 정교화하는 옵션 병기.
- **버린 대안**: 수정 횟수를 숫자로 못 박는 안(예: "방향당 피드백 2회 이내"). 첫 회신부터 횟수 제한을 거는 것이 관계상 부담이라 판단해 진행 중 협의로 넘김. 단 이 항목은 미해소 리스크로 남음.
