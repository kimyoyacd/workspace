## 한 줄 정의

**통보가 아니라 공유.** 정보를 정확히 주되, 상대가 판단할 여지를 남기고,
요구 앞에는 우리가 먼저 움직이겠다는 의사를 둔다.

---

## 어미 규칙 — 여기서 톤의 8할이 결정된다

| 상황 | 쓰는 말 | 쓰지 않는 말 |
|---|---|---|
| 우리가 할 일 | **~할 예정입니다 / ~하겠습니다 / ~드리겠습니다** | ~합니다 (단정·통보로 읽힘) |
| 상대에게 요청 | **~부탁드립니다 / ~주시면 감사하겠습니다** | ~해 주세요 / ~필요합니다 |
| 확인된 사실 | **~로 확인하였으며 / ~로 이해했습니다** | ~입니다 (일방 확정) |
| 리스크·가능성 | **~있어 보입니다 / ~할 것 같습니다** | ~합니다 / ~될 것입니다 (단정) |
| 비용·일정 예고 | **~이뤄져야 할 수 있어 참고차 미리 말씀드립니다** | ~비용이 추가됩니다 (청구로 읽힘) |
| 중요도 강조 | **~것이 매우 중요할 것 같습니다** | ~해야 합니다 |

핵심은 **"~예정입니다"** 다. 같은 내용도 "진행합니다"보다 "진행할 예정입니다"가
계획을 공유하는 어조가 되어, 상대가 이견을 낼 자리가 생긴다.

## 문단 구조

### 인사 — 상황 + 감사, 두 겹으로
```
오늘 미팅으로 직접 찾아뵙고 인사드릴 수 있어 반가웠습니다.
사업 전체 구조부터 화면별 기획 의도까지 상세하게 설명해 주신 덕분에
프로젝트 맥락을 깊이 있게 이해할 수 있었습니다.
바쁘신 와중에 상세히 설명해 주셔서 다시 한번 감사드립니다.
```
- 만난 사실 → 상대가 해준 것 → 그 덕에 우리가 얻은 것 → 감사
- **감사를 구체적으로.** "감사합니다" 한 줄로 끝내지 않는다.

### 본문 — 번호 + 소제목
- 1. 주요 논의 및 회의 내용 (합의된 것)
- 2. 예상 프로젝트 진행 일정 및 주요 액션 아이템 (표)
- 3. 기타 확인 및 협의 요청 사항 (상대 숙제)

소제목은 **볼드 + 줄바꿈**, 항목은 `·` 불릿. 과한 계층을 만들지 않는다.

### 일정표 — 주체를 태그로
| 일정 | 구분 | 주력 과업 | 주요 내용 및 요청 사항 |

- **`[NHN]` / `[HL]`** 태그로 주체 표기. 표를 훑기만 해도 자기 몫이 걸러진다.
- 날짜와 요청이 문단에 섞이면 상대가 "내가 언제까지 뭘 해야 하는지"를 다시 읽어야 한다.

### 맺음 — 협조 → 요청 → 책임 → 초대
```
그 부분은 저희도 최대한 적극 맞춰 진행할 예정입니다.
다만, 정해진 기간 내에 차질 없이 진행하기 위해
양사 간 피드백 과정을 최소화하고 긴밀하게 협업하는 것이 매우 중요할 것 같습니다.
프로젝트가 차질 없이 마무리될 수 있도록 끝까지 잘 챙기겠습니다.
궁금하신 점이나 의견이 있으시면 언제든 편하게 말씀해 주세요.
```
**순서가 중요하다.** 요청을 먼저 하면 요구로 읽힌다.
우리가 맞추겠다는 말이 앞에 와야 그 뒤의 요청이 협업 제안이 된다.

서명은 `김효정 드림`.

## 민감한 것을 다루는 법

### 비용이 발생할 수 있을 때
청구가 아니라 **예고**로 둔다.
> 본 사업 내 BI 제작 포함 여부 확인 부탁드립니다. **(진행 시 별도 제작 비용 협의 필요)**

> 작업 범위에 따라 일정/비용 산정이 별도로 이뤄져야 할 수 있어 **참고차 미리 말씀드립니다.**

### 상대가 늦으면 우리가 늦어질 때
책임을 지우지 않고 **구조를 설명**한다.
> 정해진 기간 내에 차질 없이 진행하기 위해 양사 간 피드백 과정을 최소화하고
> 긴밀하게 협업하는 것이 매우 중요할 것 같습니다.

### 아직 안 정해진 것
결론을 미리 적지 않는다. 사실만 짚고 결정권을 넘긴다.
> 아직 정하지 못한 것 같아 확인 부탁드립니다. 편하신 방향으로 정해 주시면 그에 맞추겠습니다.

### 범위를 벗어난 요청
"범위 외입니다"로 자르지 않는다. **포함하되 형태를 명시**하고 확장은 별도로 연다.
> 아이콘은 기존 세트 기반의 스타일 가이드 형태로 정리됩니다.
> 신규 풀 세트 제작처럼 범위가 커지는 작업이 필요하시면 그 부분만 별도로 협의드리면 될 것 같습니다.

## 하지 말 것

- **"~합니다"로 짧게 끊기** — 통보처럼 읽힌다. 이게 가장 흔한 실수다.
- **부정형 반복** — "범위 외입니다"가 두 번 나오면 거절 메일이 된다.
- **제약 조건을 메일 전체에 분산** — 방어적으로 읽힌다. 한 섹션에 모은다.
- **리스크를 단정적으로 경고** — "~하면 일정이 무너집니다" 대신 "~할 것 같습니다".
- **항목만 나열하고 협조 의사 생략** — 요구서가 된다.
- **과한 수식어·감정 과잉** — 담백하게. "정말", "너무" 류는 쓰지 않는다.
- **문장을 억지로 짧게 자르기** — 호흡이 자연스러우면 길어도 된다.
